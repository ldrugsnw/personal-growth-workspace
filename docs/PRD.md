Personal Growth Workspace

Product Requirements Document v1.2

1. 제품 정의

한 줄 소개

자유롭게 하루를 기록하면, 진행 중인 활동과 그동안의 성장을 정리해 주는 개인용 웹 애플리케이션.

해결할 문제

* 여러 프로젝트와 학습을 병행하면서 현재 진행 상태를 파악하기 어렵다.
* 오래 쉬었던 활동을 재개할 때 다음에 무엇을 해야 할지 기억하기 어렵다.
* 실제로 많은 것을 배웠어도 과거의 학습 과정과 성취를 한눈에 확인하기 어렵다.
* 기록 자체가 번거로우면 지속적으로 사용하지 않게 된다.

핵심 가치

기록은 간단하게, 현재 상태는 명확하게, 성장은 시간의 흐름에 따라 확인할 수 있게 한다.

2. 대상 및 사용 환경

* 단일 개인 사용자
* iPad Safari와 모바일 브라우저 우선
* 데스크톱 반응형 지원
* 하루 단위의 의무적 기록이나 연속 출석 강요 없음
* 학습 또는 개발을 마친 후 1~2분 내 기록 완료 목표

3. 핵심 사용자 흐름

일반 기록

1. 홈 화면에서 자연어로 오늘의 활동을 입력한다.
2. AI가 입력을 하나 이상의 활동으로 분류하고 구조화한다.
3. 사용자에게 분석 결과를 표시한다.
4. 사용자가 활동 연결, 요약, 현재 상태, 다음 행동을 검토·수정한다.
5. 승인된 결과만 저장한다.
6. 활동 현황과 성장 타임라인이 갱신된다.

첫 실행 온보딩

1. 기존 활동을 자유롭게 설명한다.
2. AI가 활동별 초기 정보를 제안한다.
3. 사용자가 수정·승인한다.
4. 활동을 일괄 생성한다.
5. 초기 상태는 실제 수행 기록으로 간주하지 않는다.

AI를 사용하지 않는 수동 활동 등록과 기록 작성도 지원한다.

4. 주요 화면

홈

* 자유 입력창
* AI 분석 실행
* 최근 기록 목록
* 빈 데이터 상태 안내

AI 분석 검토

* 원본 입력 확인
* 활동별 분석 결과
* 기존 활동 변경 및 신규 활동 승인
* 내용 수정 및 저장
* 분석 취소 시 원본 보존

활동

* 진행 중 / 보류 / 완료
* 개발 / 학습·독서 / 자격증·시험
* 현재 상태 및 다음 행동
* 활동 추가 및 수정

활동 상세

* 현재 상태
* 다음 행동
* 관련 기록
* 기록 수정 및 삭제

성장

* 전체 기록 타임라인
* 활동별 필터
* 날짜순 정렬
* 배운 점과 성취 강조
* 원본 기록 상세 조회

설정

* JSON 백업·복원
* 데이터 관리
* 앱 정보

5. MVP 필수 기능

FR-01 활동 관리

* 활동 생성·조회·수정
* 유형 및 진행 상태 관리
* 현재 상태와 다음 행동 직접 수정
* 삭제 시 관련 기록 처리 여부 확인

FR-02 기록

* 자유로운 텍스트 입력
* 하나의 입력에서 여러 활동 기록 생성 가능
* 발생일과 저장일 구분
* 기록 수정·삭제 지원
* AI 없이 수동 저장 가능

FR-03 AI 구조화

* 한 번의 LLM 요청으로 분석
* 기존 활동 연결 및 신규 활동 제안
* 진행 내용, 배운 점, 성취 추출
* 현재 상태 및 다음 행동 변경 제안
* 불확실한 내용은 비워두거나 사용자 확인 요청
* 저장 전 검증 및 사용자 승인 필수

FR-04 현재 상태 일관성

* 활동의 현재 상태와 다음 행동을 별도로 저장
* 해당 값을 갱신한 기록의 ID를 출처로 저장
* 출처 기록을 수정·삭제하면 현재 상태에 대한 영향 확인
* 사용자 승인 후 필요한 상태 변경 적용
* 출처가 아닌 과거 기록 수정은 현재 상태를 임의로 덮어쓰지 않음
* 전체 기록 자동 재계산 엔진은 MVP에서 제외

FR-05 성장 타임라인

* 모든 활동의 기록 조회
* 특정 활동만 필터링
* 배운 점과 성취를 중심으로 표시
* AI 성장 스토리 자동 생성은 제외

FR-06 데이터 보존

* IndexedDB 로컬 저장
* JSON 내보내기·가져오기
* 스키마 버전 포함
* 파일 검증 후 복원
* 복원 전 기존 데이터 처리 확인
* 가져오기 실패 시 기존 데이터 유지

6. 데이터 모델

Activity

* id
* type
* title
* status
* currentState
* nextAction
* currentStateSourceLogId (nullable)
* nextActionSourceLogId (nullable)
* metadata
* createdAt
* updatedAt

JournalEntry

* id
* rawText
* occurredAt
* createdAt
* updatedAt

ActivityLog

* id
* activityId
* journalEntryId (nullable)
* summary
* learning
* achievement
* occurredAt
* createdAt
* updatedAt

BackupPayload

* schemaVersion
* exportedAt
* activities
* journalEntries
* activityLogs

식별자는 UUID를 사용한다. 날짜는 일관된 형식으로 저장하고, 화면에서는 사용자 현지 시간으로 표시한다.

현재 상태의 출처 ID가 가리키는 기록이 수정·삭제될 때에는 명시적인 사용자 확인 절차를 거친다.

7. 기술 스택 제안

* React
* TypeScript
* Vite
* IndexedDB (Dexie 검토)
* Vitest
* React Testing Library
* Vercel 배포
* AI 분석용 서버리스 API

AI 호출 시 비밀 API 키를 클라이언트에 노출하지 않는다. 서버리스 엔드포인트에는 접근 제어와 사용량 제한을 적용한다.

8. 비기능 요구사항

* iPad 및 모바일 반응형
* 입력 중 데이터 손실 방지
* 로컬 저장 실패 시 오류 안내
* AI 호출 실패 시 수동 저장 가능
* 저장 전 사용자 검토
* 사용자 동의 없는 자동 데이터 수정 금지
* 기본적인 키보드 접근성
* 주요 데이터 조작에 대한 테스트

9. MVP 제외 기능

* 로그인 및 클라우드 동기화
* GitHub 자동 연동
* AI 후속 질문 대화
* AI 주간·월간 회고
* 고급 통계 및 시각화
* 푸시 알림
* 협업
* 복잡한 상태 변경 이벤트 시스템

10. 개발 마일스톤

M1. AI 없는 기록 시스템

* 활동 CRUD
* 기록 CRUD
* IndexedDB
* 홈·활동·성장 기본 화면
* 상태 출처 및 수정 영향 확인

M2. AI 분석

* 자유 입력 분석 API
* 구조화된 응답 검증
* 분석 결과 검토·수정
* 승인 후 저장

M3. 온보딩

* 기존 활동 일괄 분석
* 초기 활동 검토 및 생성
* 빈 상태와 첫 실행 경험

M4. 안정화

* JSON 백업·복원
* 모바일 UX 개선
* 오류 처리
* 통합 테스트
* 실제 사용 검증

11. 수용 기준

* 사용자는 AI 없이 활동과 기록을 만들 수 있다.
* 기록을 저장하면 해당 활동 상세와 성장 화면에 나타난다.
* 여러 활동이 포함된 입력을 분리해 검토할 수 있다.
* AI가 제안한 정보는 승인 전 저장되지 않는다.
* 과거 기록을 수정해도 최신 상태가 조용히 잘못 덮어써지지 않는다.
* 백업한 JSON으로 기록을 복원할 수 있다.
* iPad Safari에서 주요 흐름을 수행할 수 있다.
* 일반적인 기록 작성은 2분 이내 완료할 수 있도록 설계한다.

12. 출시 후 검증

2~4주간 실제 사용하면서 다음을 확인한다.

* 기록하는 데 걸리는 시간
* AI 분석 결과를 수정하는 빈도
* 활동을 재개할 때 현재 상태가 도움이 되는지
* 성장 타임라인을 다시 열어보는지
* 사용하지 않는 기능과 불편한 단계

이 결과를 바탕으로 클라우드 동기화와 GitHub 연동의 필요성을 재평가한다.
