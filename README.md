# Personal Growth Workspace — M1

AI·인증·외부 API 없이 사용하는 개인 성장 기록 앱입니다. React + TypeScript + Vite, Dexie(IndexedDB)로 구현했습니다.

## 실행

Node.js 22.12 이상(검증: 24.19.0), npm을 사용합니다.

```sh
npm ci --cache /tmp/pgw-npm-cache
npm run dev
```

```sh
npm test
npm run build
```

## 사용 흐름

1. 홈에서 첫 활동을 만듭니다. 활동 화면에서 제목·유형·진행 상태를 관리할 수 있습니다.
2. 홈의 기록 작성 또는 활동 상세의 기록 추가로 요약을 남깁니다. 배운 점·성취는 선택 사항입니다.
3. 현재 상태·다음 행동 갱신을 선택하면 해당 기록이 필드의 출처가 됩니다.
4. 상세 및 성장 화면에서 기록을 확인합니다. 성장은 발생일 최신순이며 활동별로 필터링할 수 있습니다.

출처 기록을 수정·삭제할 때 연결된 상태의 유지/비우기/취소를 명시적으로 선택합니다. 삭제하면서 유지하면 값은 보존하고 출처 연결만 해제합니다. 과거 기록으로 상태를 자동 재계산하지 않습니다. 활동 삭제는 관련 기록의 개수를 표시한 확인 후 기록과 함께 처리합니다.

## 구조

- `src/App.tsx`: 홈·활동·상세·성장 화면, 입력 폼과 변경 확인
- `src/repository.ts`: 데이터 타입, IndexedDB 스키마, 트랜잭션 기반 데이터 접근
- `src/style.css`: 모바일·태블릿 반응형 스타일
- `src/App.test.tsx`: 주요 화면 흐름·필터·확인 절차 테스트
- `src/repository.test.ts`: 저장 유지·출처 정책·삭제 일관성 테스트
- `docs/PRD.md`: 제품 요구사항

## 검증과 한계

Vitest/React Testing Library 9개 테스트 및 TypeScript/프로덕션 빌드를 통과했습니다. Chromium에서 390×844, 820×1180 뷰포트로 활동 생성 → 기록 저장 → 성장 조회 → 실제 페이지 새로고침 후 유지, 가로 넘침 없음, JS 오류 없음을 검증했습니다. 실제 iPad Safari 및 저장 공간 부족 상황은 검증하지 않았습니다.

데이터는 브라우저와 사이트 주소별 IndexedDB에만 저장됩니다. 브라우저 데이터 삭제 시 복구할 수 없으며 JSON 백업·복원은 M4 범위입니다. 입력 중인 폼은 저장 전 새로고침하면 유지되지 않습니다. 여러 탭의 동시 편집을 실시간 동기화하지 않습니다.

M2에서는 서버리스 분석 API(서버 측 비밀키·접근 제어·사용량 제한), 구조화된 응답 검증, 분석 결과 검토·수정 및 승인 후 저장을 추가합니다. 원본 입력과 여러 활동 기록을 연결할 JournalEntry 모델 및 DB 마이그레이션도 필요합니다.
